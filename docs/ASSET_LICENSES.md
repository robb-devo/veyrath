## Project licence

The project owner has not chosen a licence. Until they do, VEYRATH's own code and assets are
**all rights reserved** (`fabric.mod.json`: `All-Rights-Reserved`). This must be settled
before any public release or published modpack.

## Rules for future assets (Chapters 01 to 05)

- Record the origin, the author, the licence (with a link to the licence text), the attribution
  text and any modification made.
- Acceptable: own work; CC0; CC-BY with recorded attribution; and commercial libraries whose
  licence allows use in a distributed game mod, with the licence kept on file outside the
  repository if it cannot be published.
- Not acceptable: assets ripped from games, assets of unknown origin, "free for personal use"
  assets in anything that will be distributed, and AI-generated assets without a recorded tool
  and terms of use.
- Audio (Chapter 03): licensed Foley and libraries only, with usage rights documented per file
  or per library.
